# Superstore Sales Data Analysis

An exploratory data analysis (EDA) project that analyzes a real-world Superstore sales dataset to uncover meaningful trends and business insights.

## Project Objective

The objective of this project is to explore and analyze Superstore sales data using Python and identify patterns related to sales, profit, product categories, and regions.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* JupyterLab

## Dataset

The dataset contains information about Superstore orders, including:

* Order and shipping dates
* Product categories and sub-categories
* Customer segments
* Geographic regions
* Sales
* Quantity
* Discounts
* Profit

## Analysis Performed

So far, the project includes:

* Data loading and initial exploration
* Data structure and data type inspection
* Missing value analysis
* Duplicate value analysis
* Date conversion and preparation
* Sales analysis by category
* Profit analysis by category
* Sales analysis by region
* Profit analysis by region
